# review-widget composition manifest — Eden Origin hub

Composed 2026-07-17 into `public/hub/` (hub root) and mirrored into `public/hub/website/`
so both the proposal hub and every website page are reviewable.

## Profile
Light cut ("Credo shape"): no auth, name prompt on first comment, **localStorage
fallback** (FIREBASE_CONFIG intentionally empty for the demo — paste a Firebase RTDB
web config into `review.config.js` to switch to shared comments).

## Source referenced
- `organization-template/library/features/review-widget/FEATURE.md` (composition spec)
- Reference composition: `credo/public/social-hub/` (review-bootstrap.js, review-mode.js,
  review-mode.css, review.config.js) — the proven light-cut deliverables.

## Deliverables (public/hub/)
- `review.config.js` — `window.EDEN_REVIEW_CONFIG`; Serbian `REVIEW_LABELS`; empty
  `FIREBASE_CONFIG` (localStorage demo).
- `review-bootstrap.js` — inert until `?review=1`; floating "Komentari" entry button;
  resolves `review-mode.{css,js}` relative to its own script URL (multi-depth safe);
  injects the widget into `body||documentElement`.
- `review-mode.js` — the widget (IIFE-isolated per js-isolation.md). `window.prompt`
  calls wrapped in `safePrompt()` so sandboxed previews don't abort init.
- `review-mode.css` — scoped under `[data-review-mode="on"]`; re-themed to North Star
  copper (`--rw-deep:#b06a3a`) on charcoal (`--rw-ink:#2b2b33`).

## Per-project resolution
- All `credo`/`CREDO_*` identifiers scrubbed to `eden`/`EDEN_*` (leak-clean).
- Loaded on the hub by injection from `content.js` (hub.html chassis stays unedited);
  loaded on website pages via `website/_src/build.py` FOOT (before `</body>`), with the
  4 files copied to the website root at build time.

## Verified
Inert entry button (no `?review=1`); `?review=1` renders banner + sidebar + 375 anchors
on the hub and 61 on a product page; hover pill opens the composer; zero console errors;
depth-aware asset resolution confirmed from `/website/proizvodi/violaverde-borovnica/`.
